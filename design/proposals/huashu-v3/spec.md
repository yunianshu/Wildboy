# 野小子后台首页设计提案

本轮只交可选择的设计，不修改生产界面。huashu-design v3.3.0，提交 e8d1148a80d5a281d4247cffe320add3df017928，完整 445 文件已按 Git blob 摘要核验。来自 https://github.com/alchaincyf/huashu-design 。本机此前未安装，此次补装最新版；本轮已直接读取已安装的 SKILL.md 并执行。

## 内容与范围

- 对象：Web 管理员首页 `/activities`，Vue 3 原文件 `admin/src/views/ActivitiesView.vue`，外壳 `admin/src/App.vue`。
- 任务：搜索活动、按分类和状态筛选、查看价格和报名名额、编辑、进入收费活动订单或免费活动名单、新建、刷新、分页。
- 数据契约：title/category/location/coverUrl/startAt/priceCents/registeredCount/capacity/pendingPaymentCount/status；金额分转元，北京时间。状态仅草稿、已发布、已取消；分类本周活动、国内游行、假期活动、休闲活动，以代码映射为准。
- 不增加仪表盘统计、营收、到场率、待办、日历、批量操作等接口未提供的内容。封面来自已有 coverUrl，设计图使用仓库配图。
- 8 条样例仅用于设计演示，与生产数据无关。已获原始任务允许；预览外壳标注“设计预览”。3 版字段内容一致。
- 附属界面：同一方案的主次按钮、搜索/选择框、标签、空状态，以及现有编辑器的发布确认弹窗。弹窗不改发布业务规则。
- 首页专属 `miniprogram/src/pages/home/index.*`、原导航/TabBar、资源与业务不修改；生产 CSS 不修改。

## 用户原话与优先级

“不要蓝灰”；希望阳光、有活力；“组件你是不是没有统一，还有弹窗”；“不要有那么多的说明性文字，简洁点”；“先改设计图，再调整界面”；“先做一个界面看看吧”；“设计几种方案我来选择”；上一轮三套配色“都不合适，重新设计”。新方案尚未选定，早前橙色选择已经被后续否决取代。

## 交付与步骤

六个候选先在 Pen 中画出关键屏并导出六格图，选三种不同结构扩展为完整 1440×900 首页。每版在 Pen 完成后实际读取结构，再写独立 HTML 预览（1440×900 和 375×812 验证）。设计源是 `design/设计图文件.pen`，新增提案区域，与旧设计共存。每版提供弹窗和组件局部稿。截图、源数据、映射和打磨记录保存本目录。

先看六格小样 → 三版完整稿 → 用户选择 → 才进入全端设计和生产重构。设计阶段不清除登录、草稿等用户数据。

## Form 五问

角色：高频操作页面；距离：桌面约 60cm，兼容手机查看；温度：明亮、轻快但能久用；容量：1440×900 展示导航、筛选和 6–8 行，正文 14–16、标签至少 12；母题：户外活动的路线封面、出发时间和实际报名名额。没有通用营销 hero，没有无来源统计卡。

## 统一边界

每版内部共用字号和 4/8/12/16/24/32 间距，按钮与输入同高 44，主动作只用一个品牌强调色；状态色不与品牌色混淆；圆角在同一版内统一。弹窗宽 480 或 520、内边距 24、标题 22、底部取消与确认并排，Esc 关闭、焦点圈可见。界面仅必要标题和短标签。
