# 品牌与素材

品牌信息直接来自用户仓库 PRODUCT.md 和首页资产，不拿外部同名品牌替代。

- 野小子：`miniprogram/src/assets/platform-brand-original-transparent.png`，保留原登山者、山峰和手写字；已经实际看图。只在预览中按 contain 缩放，不改变首页源文件。
- 封面：仓库 `hero-hiking.jpg`、`category-weekly.jpg`、`category-domestic.jpg`、`category-holiday.jpg`、`category-leisure.jpg`；用作设计示例配图，不宣称是某条真实活动的现场照。
- 页面和组件：`admin/src/App.vue`、`views/ActivitiesView.vue`、`components/FormModal.vue`、`ConfirmDialog.vue`；已读当前页面数据契约及导航。
- 字体沿用 Noto Sans SC（Google Fonts / OFL）及 PingFang SC、Microsoft YaHei 兜底，数字使用 tabular-nums。
- 既有橙色主题已被用户否决，新候选变量使用独立 hd-* 命名，不覆盖 rf-*。
- 参考作品只用于内部研究和方向卡，不将 Notion 或 monday.com 的 logo、界面搬进产品。

色彩推导：A 从户外叶绿与保留首页的品牌森林绿提亮，B 从运动用品的鲜明莓红色语境配白，C 从阳光杏黄色语境抽取低面积强调。配色为设计建议，非既有品牌强制色。至少 4.5:1 正文对比。
