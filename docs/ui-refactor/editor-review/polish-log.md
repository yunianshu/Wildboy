### 打磨记录

第一轮在桌面后台和微信模拟器检查了相同内容。长封面遮住文章标题、活动图库挡住集合信息、内容块没有可见的复制入口，是操作和阅读路径中最明显的三处问题。

第二轮对照粘贴预览与小程序实页，检查片段背景、中文标题、强调、表格和配图。移除后台全局表格样式对片段的干扰，让活动编辑窗的保存操作固定在底部。另用含换行、反引号和 HTML 实体的样本检验复制后独立修改与再次保存，确认原位换图保留图片所在位置和宽度。

### 覆盖范围

后台 21 个路由分别在 1440px、375px 视口走查，检查页面标题、可见错误和整页横向溢出。复制确认窗另外检查了 320px 到 1440px 五档宽度。小程序对活动列表、活动详情、文章阅读做了模拟器视觉复核，并对首页、商城、我的、订单与资料入口做了源码走查。测试内容使用隔离的本地数据库。

Web 后台 220 项、小程序 379 项测试通过，两端均已构建。后端首次全测时，两组集成测试的临时 PostgreSQL 启动超时。使用独立临时目录复跑后，40 份测试报告合计 392 项通过，失败、错误和跳过均为零，服务端已完成打包。

截图中「山脊上的集合点」为验证公众号复制效果构造的富文本样本。来自原文的互动卡片、音视频和动效无法直接复现，原生排版会随屏宽、系统字体换行。可转存的微信 CDN 图片固化为本地媒体，失败的图片保留原链接并在粘贴时提示。
