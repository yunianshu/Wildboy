# 功能设计画板索引

设计方向：A 晨光绿白。以下画板全部从现有业务功能重新构建，不沿用 B 的页面结构。

54 张可编辑画板：22 个后台页面/模式、19 个小程序页面、12 个条件/异常状态和 1 张设计规范。所有数据为演示。
