# WildBoy 功能优先 Pen 重设计验证

## 最新需求与边界

- 按用户最新方向，从项目实际功能、角色和业务流程重建设计；不以 B 画板为布局模板。
- 只保留 A「晨光绿白」视觉方向。活动与商品分别设置会员优惠，不增加课程业务。
