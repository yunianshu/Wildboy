## 实施摘要

- Web 外壳由 216px 侧栏改为 B 顶部横向导航（72px：原始 Logo + 五组业务大类下拉 + 管理员区），页面标题移入子导航行（28px 主色 + 兄弟页链接；编辑/详情页为返回入口 + 标题）。各视图保留语义 h1（视觉隐藏），测试与读屏不受影响。
- `/activities` 重构为两列左图右信息卡片（H3X2a 几何：封面 176px、圆角 12、标题 18/600、价格 18/600 主色、44px 操作行），搜索仅标题、分页 size=8、分转元两位小数、免费/收费分流、待支付仅收费且数量>0，业务逻辑未变。
- 控件统一 44px、10px 圆角、弹窗 16px 圆角/24px 内边距；焦点圈改用主色（白底对比 5.57:1）。
- 双端令牌继续沿用 rf-* 名称（历史命名），值全部为 B；小程序 30 个页面窗口配置与内联色一并换 B，共享受保护组件（custom-tab-bar、ui-state/content-view/markdown-view 原版）未动。
- B 扩展语义色（danger #B03A2E、info #6E4A63 等 17 项）作为显式变量写入 Pen 并随读回生成，非实现层私造。

- 运行中的用户 Vite dev 服务器（5173）未强制重启；其依赖缓存已被 `optimize --force` 重建，下次访问生效。
