# 双端界面重构 · 2026-11-17

本轮依据用户明确要求执行。范围是 Web 全部 21 个路由、小程序 29 个非首页路由及其现有附属界面；小程序 `pages/home/index` 保留，仅验证。历史文档不代表本轮已完成或已验证。

## 审查与范围

路由依据 `admin/src/router.ts`、`miniprogram/src/app.json` 以及实际页面入口。Web `/` 重定向 `/activities`，因此后台首页就是活动工作台；`/waitlist` 是旧入口重定向，不恢复候补业务。小程序没有分包；首页由 pages 首项、自定义 TabBar 的探索项和 `utils/tab-bar.ts` 共同确认，不能凭文件名判断。未注册的 WaitlistView 和 `.wxml.new` 备份排除。

完整逐页清单见 [inventory.json](inventory.json)，包含端、模块、路由、文件、角色、接口引用、入口、事件、附属界面和四阶段状态。每页的实际字段与设计内容、画板和来源见 [design-map.json](design-map.json)。API 字符串提取只是辅助索引，真实调用同时见 Web `api.ts` 和小程序 `utils/api.ts`，不能将路由字符串当作完整接口契约。

技术栈：后台 Vue 3 / TypeScript / Vite，原生 CSS、Vditor；小程序是微信原生 TypeScript / WXML / WXSS，四个自定义 Tab，原生导航与平台组件。服务端 Java 21 / Spring Boot / PostgreSQL。本轮不替换框架、不修改服务端业务。

## 首页保护基线

`pages/home/index.{ts,wxml,wxss,json}`、app.ts/app.json/app.wxss、原 custom-tab-bar、原 ui-state、请求与状态工具、字体/图标/图片资源均纳入 [home-baseline.json](home-baseline.json) 的 81 项 SHA-256 基线。首页组件树、首页弹层、分类/文章/弹窗/活动入口及参数均保留。后台维护首页的真实配置能力仍在范围内。

原生微信开发者工具修改前截图保存在 `design/assets/home-native-before-2026-11-17.png`，Pen `Q78i6` 仅展示此基线。新主题只由非首页页面自己的 wxss 引入，必要组件与图标用独立副本，原共享资源不修改。原 TabBar 表现保持一致，含四个入口、滑动切换与安全区。

## 设计规则与数据读取

在原 Pen 文件保留可编辑页面、附属界面和原组件，通过 MCP 实际编辑并读取。新增规范板 `iSDAE`，变量 `rf-*`；路由对应全部画板见映射。蓝灰主色 `#315B78`、灰白底 `#F2F5F8`、白色内容 `#FFFFFF`、深文字 `#202D3A`、辅助文字 `#627384`、边框 `#D8E1E8`。颜色来自实际解析变量，不用截图猜测。保留成功/警告/错误业务语义。

Web：216px 白色侧栏、60px 顶栏、28px 内容边距，26px 页面标题、14px 正文、13px 表格，40px 控件，8px 控件圆角、12px 卡片圆角。小程序：16px 页边距、24px 标题、14px 正文、48px 表单控件、44px 可触达操作、12px 卡片圆角。字体使用系统 Noto Sans SC/PingFang SC/Microsoft YaHei 回退，不强制网络字体。图标沿用原 SVG 语义和形状，新颜色使用独立资源。

所有范围内页面已逐节点读取布局、约束、样式、资源、实例和变量解析结果；数据保存在 `pen-readback.json`，映射附 SHA-256 摘要。老的 metadata.route 无法通过当前工具 Update 改写，文章页已用真实节点 context/name 标注正确路由，映射优先使用 context。这是工具限制，不伪造 metadata。

规范板统一列出加载、空数据、筛选无结果、失败/重试、无权限、提交中、校验失败、成功、部分失败与版本冲突；具体页面附属画板见映射。支付未确认仍保留“查询订单状态”，不将客户端反馈当作支付成功。

以下为实现补充约束，并非声称 Pen 原生交互返回：Web ≤720px 使用原移动导航，表格在自身容器滚动，弹窗焦点与 Escape 沿用现有组件；小程序适配动态胶囊位置、状态栏、键盘与底部安全区，固定操作不挡内容。数据长文本换行、标题两行截断、图片 aspectFill；页面高度随真实数据增长，Pen 样例不写入生产。
