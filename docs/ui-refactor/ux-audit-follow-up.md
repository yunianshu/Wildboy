## 首页保护

`pages/home/index`、自定义 TabBar、`app.json` 和 `app.wxss` 的 Git 差异为空。探索页的刷新与入口行为建议按原保护范围保留。首页仍通过后台原有接口读取配置。

## 验收范围

- 后台构建与 205 项测试通过。Chromium 使用模拟接口验证活动订单的登录深链、筛选请求、脱敏和退款弹窗，以及 375px 下的日期时间选择。
- 小程序原生资源构建和 360 项自动化测试通过，含首页基线、会话切换、报名草稿和售后回页。微信开发者工具连本机隔离接口，验证报名页可以打开页内参与人草稿，且确认前不增加参与人数。
- 服务端全量回归 370 项通过。新增运营指标直达筛选后，53 项定向集成测试和服务端打包通过。
- 已重建后台 Vite 依赖缓存和小程序 `dist`，小程序构建产物恢复生产 HTTPS 配置。
- 当前工作区的代码实现依据是审查文档和已有界面。按用户要求，Pen 等额度恢复后再同步。

## 本轮补齐

- 报名 CSV 包含当前筛选的全部记录。导出接口只返回姓名、脱敏手机号、报名状态和时间。
- 商城关键词搜索覆盖全部分类。用户和会员列表在同一次登录内返回时恢复已提交的关键词和页码，关键词留在内存里。
- 微信对账提供上一页和下一页，沿用微信游标和已提交条件，支付时间按北京时间查询。
- 后台按小程序 AppID 回显最近一次获微信确认的消息跳转路径。历史上通过外部渠道设置的值仍无法从后台读取。
- 审计日志显示已知操作的中文名称，未知项显示「其他历史操作」，可从悬停提示查原始动作。

## 本轮验证

- 后台构建和 205 项自动化测试通过。Chromium 使用模拟接口验证 24 条脱敏 CSV 导出、搜索回页恢复、消息路径回显及 375px 下的对账前后翻页。
- 服务端定向测试 96 项通过并完成打包，覆盖导出授权与脱敏、消息路径保存、订单中心、退款及发货上报。
- 小程序构建和 361 项自动化测试通过。微信开发者工具验证跨分类搜索、文章分享参数和模拟微信地址回填。
- 已重建后台 Vite 缓存和小程序生产构建，并清理微信开发者工具的项目编译缓存。首页继续以源码差异和自动化基线核对。
- 真实微信支付、退款、分享送达、地址授权及真机验证仍待验。本轮各项微信验证使用本地隔离数据或模拟接口。
