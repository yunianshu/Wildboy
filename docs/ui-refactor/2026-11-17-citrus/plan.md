# 阳光柑橘 · 双端界面修订

按用户确认采用亮橙、奶油白与草木绿，减少重复说明，统一组件和弹窗。顺序为修改 Pen → 设计自检与保存 → 重新读取结构化数据 → 实现 → 运行验证。

## 范围与基线

21 个 Web 有效路由全部纳入；小程序 30 个注册页面中 29 个重构，`pages/home/index` 保留。没有分包，废弃候补页与备份页面不恢复。真实路由、文件、功能、权限、接口、关联页面和逐页状态见 [inventory.json](inventory.json)；现有业务流程与审查记录沿用 [前版审查](../2026-11-17/plan.md)。

首页由 app.json 启动顺序、自定义 TabBar 的“探索”入口及实际跳转共同识别。首页专属文件、TabBar、原公共组件、全局 app 样式、请求及状态逻辑共 81 个文件沿用修改前的 [SHA-256 基线](home-baseline.json)，没有重建或刷新基线。新主题仅在非首页页面导入。

首页入口到活动、商品、文章和登录后的返回参数继续使用原实现。后台的首页四入口、弹窗内容、文章及官方介绍管理仍保留真实接口；本轮不固定首页数据。金额仍使用整数分、日期沿用北京时间、权限与版本冲突由既有业务和服务端处理。

## 色彩与组件

| 用途 | 值 |
| --- | --- |
| 主操作 / 主操作文字 | #FF8A2C / #33251C |
| 页面 / 内容表面 | #FFF8EE / #FFFFFF |

| 成功状态 / 成功背景 | #426B37 / #EDF5E6 |

网上参考了 [Colorffy Sunny](https://colorffy.com/palettes/EZK3Hki3yJNuF90CJSMS) 的阳光橙黄组合，以及 [Canva Spring Contrast](https://www.canva.com/colors/color-palettes/spring-contrast/) 的黄绿关系。以上实际界面色值为本项目适配，并非照搬完整网站色板。语义色使用方式参考 [Adobe Spectrum](https://spectrum.adobe.com/page/color-system)。

正文、辅助文字、橙色按钮文字、链接对比度分别为 13.05、5.25、6.27、6.60；白底字段边界为 3.16。主按钮使用深色文字。

Web 按钮、输入框 40px；移动主要操作及输入框 48px；关闭热区 44px。控件圆角 10px、内容区 12px、弹窗 16px。弹窗标题 18px，Web 内边距 24px、小程序 20px，内部间距 16px。Web 弹窗宽度 440/560/760/960px，移动按视口减 32px 自适应。保留原系统中文字体与线形 SVG 资源，不增加远程字体依赖。

按钮、字段、标签、列表、空态与加载态共享 rf-* 变量。Web 确认与表单统一使用 FormModal；自定义小程序弹层统一使用 ui-dialog。内容超高时正文滚动，标题、关闭与主操作保持可达。提交中禁止关闭与重复提交。Web 支持焦点循环、Esc 和关闭后返回触发点。放弃草稿、隐私揭示、补报等原浏览器确认改为异步统一确认，保留拒绝后的草稿、权限及接口行为。

微信原生 `wx.showModal` 与浏览器关闭标签页的 `beforeunload` 属于平台界面，保留系统表现。小程序原内联确认区域保留其交互形式，使用公共按钮和字段规范。

这些响应式、滚动、键盘和焦点规则是明确的实现补充，未伪称由 Pen 返回。文案删除重复介绍、操作教学及开发术语；付款不确定、资料用途、同意条款、冲突和不可逆操作的必要提示保留。

`scripts/ui-refresh-tokens.py` 从本版回读生成两端变量。历史命名的 slate-* 局部样式与图标目录仍保留路径，实际内容已统一为本版暖色；首页继续使用原资源。

无新增业务模块、接口、生产假数据或路由变更。测试写入仅作用于本机 19082 隔离数据库，后台测试端口 15176；不调用生产支付、发送真实通知或分享文件。构建、自动回归、Web 浏览器与微信开发者工具检查分别记录在 [verification.md](verification.md)，未执行的检查不列为通过。
