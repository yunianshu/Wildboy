原生复验使用本地 18080 API 和演示账号。商品编辑网络错误、协议状态查询失败通过客户端注入；结算协议异常、库存 150、`ui-only-address` 临时地址及“调试用户”仅为合成页面状态，未修改真实库存、发布协议或向后台保存该地址。
