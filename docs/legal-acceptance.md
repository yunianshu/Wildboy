# 动态协议独立验收

## 从用户需求确定的验收标准

1. 隐私政策与用户协议均可由经过服务端验证的管理员编辑。保存草稿不改变公开版本，只有确认发布才生成新版本。
2. 发布历史不可变，普通用户不能修改或读取未发布草稿；冲突不能静默覆盖他人的编辑。
3. 生产环境无已发布协议时不得虚构同意或让微信登录/报名通过，管理员仍可登录初始化，公开浏览、查询既有报名与取消报名不受阻。
4. 用户必须主动确认当前两协议版本，默认不勾选。后台发布新版本后旧确认不能冒充新版本确认；内容加载失败、拒绝或返回不产生同意记录。
5. 同意记录绑定真实服务端用户和版本，新增记录而不覆盖旧记录；账号切换与迟到请求不能泄漏或复用其他账号的同意。
6. 微信凭证交换失败不产生假同意。协议更新竞态须由服务端最终核对，不能依赖客户端显示状态。
7. 正文按纯文本安全展示。演示文本只在明确开发环境使用，不能声明等于正式合法合规文本，也不能替代微信平台隐私配置。
8. 保留既有活动、身份、名额、取消、管理员操作及页面导航回归，不通过删除断言、跳过测试来达成通过。

## 可复跑命令

在仓库根目录：

```sh
npm --prefix miniprogram test
node --test tests/e2e/mobile-workflows.cjs tests/e2e/legal-workflows.cjs
npm --prefix admin test -- --run
npm --prefix admin run build
# 需要 Java 21、Maven 和可运行的本机 PostgreSQL 测试依赖：
bash tests/e2e/run-api-smoke.sh
```

HTTP runner 启动独立 EmbeddedPostgres 和本机 HTTP 服务，测试完成后关闭；脚本拒绝非 loopback 地址。上述通过结果不代表生产已配置、正式协议已经法律审核或已经上线。

测试仅使用隔离环境、合成账号和演示文本，不接受真实法律协议或传输真实凭据。
