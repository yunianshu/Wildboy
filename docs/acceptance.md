# Wildboy 验收清单

这些标准从原始需求提取，而非按实现反推。验证状态将在实际运行后填写。

## 用户要求

1. GitHub 项目命名 Wildboy，代码包括微信小程序及可运行服务端。
2. 首页顺序：沉浸式轮播图 → 2×2 四个分类（本周活动、国内游行、假期活动、休闲活动）→ 装备小店一览 → 双列活动项，滚动分页显示更多。
3. 管理员可创建、编辑及发布活动；草稿不公开，普通用户无管理权限。
4. 微信用户可报名，查看报名状态。微信身份由服务端换取，不信任客户端伪造的 openid 或 role。
5. 各活动类型有原创设计配图，文件实际纳入项目；参考截图中的无关数据不进入项目。
6. 微信支付暂不接入，当前不产生付费订单，不将装备展示伪装成可购买交易。

## 完整流程与边界

- 创建草稿 → 编辑 → 发布 → 公开列表/详情 → 登录 → 报名 → 自己的报名记录。
- 重复点击和网络重试不重复占用名额；多人争抢最后名额不能超售。
- 取消自己的报名释放容量，可按规则重新报名；不能取消其他用户报名。
- 报名截止、活动开始/结束、取消活动均使用服务端时间检查。
- 编辑容量不能低于已报名人数；并发编辑使用版本检查，旧版本不能覆盖新内容。
- 草稿、个人姓名与电话不可泄漏到公共接口；管理员名单仅经权限校验访问。
- 分类切换与分页无重复/丢失，空数据、加载、失败重试都可辨识。
- 生产环境缺配置不能静默进入演示模式；dev-login 在生产不可用。
- 表单显示日期时间按 Asia/Shanghai；传输带明确时区。
- 未授权接口、非法输入、过期会话与不存在数据给出明确错误，不能显示假成功。

## 独立审查已发现并修复

- 已开始的已发布活动原可通过把新开始时间改到未来绕过编辑限制；后端已补检查原活动时间与回归测试。
- 小程序 release 环境原可因误配 devLogin 放行 HTTP；现只允许真正 develop 环境显式开发登录使用 HTTP，并测试 release 拒绝。
- 小程序非 JSON/空错误响应原可能让请求悬挂；现统一错误解析。旧请求的迟到 401 不再清除更新后的会话。
- 自己的取消报名按钮明确受报名截止/开始时间限制，不以“名额已满”错误禁止取消。
- 图片路径区分六个内置资源与服务器自定义 `/assets/`，避免将后台自定义图片误当成本地包文件。
- 管理后台标题与状态过滤明确标注为“当前页筛选”，分类由服务端全量过滤；不伪称全库标题检索。

## 可复验脚本

- `python3 tests/e2e/api_smoke.py`：仅允许回环开发服务，自动创建并取消合成活动。可通过 ADMIN_TOKEN、USER_TOKEN、USER_TOKEN_2 提供测试用户；默认使用显式 dev-login。不会使用真实微信凭据。
- `node tests/e2e/admin_browser.cjs`：需要 Playwright、Chromium、已启用开发登录的后台和真实 API。当前环境未能启动浏览器，脚本存在不等于此阶段通过。

2026-10-26 独立 HTTP 检查使用 `LocalSmokeServer` 测试启动器，验证真实网络入口而非仅 MockMvc。测试结束后服务和临时数据库已关闭；它不等同于最终可执行 JAR 的单独启动验证。可复现完整 API 验收：`tests/e2e/run-api-smoke.sh`（需要 Java 21、Maven、curl、Python 3，端口 8080 空闲）。

后续补充：后端已单独完成最终可执行 JAR 启动冒烟，因此“测试启动器不等同于 JAR 验证”的区分仍成立，但该 JAR 阶段现已另行通过。该项证据来自后端执行者的实际运行报告；HTTP 29 项是独立验收执行者亲自运行。
