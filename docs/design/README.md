- 归档日期：2026-10-26。图内“尚未实现”“独立页面尚未实现”等字样，是绘图当时的阶段标记，原样保留以避免篡改历史；**不代表当前代码尚未实现**。截至代码版本 `43e0ea0`，小程序管理员、独立登录和版本化协议管理已经实现。

- 早期图中的“隐私说明”是旧文案；当前隐私政策、用户协议及管理员编辑/发布能力见 [协议管理说明](../legal-admin.md)。六张图不包含新增协议管理页面的专项设计图。
