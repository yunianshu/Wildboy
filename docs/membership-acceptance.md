# 会员等级与收费活动验收

本次修改基于 main 的 5c26544。使用隔离云端工作区和合成用户、地址、活动及订单，不使用真实商户凭据，不发起真实扣款/退款，不部署生产。

## 范围

- 散客、会员、领队业务身份，与 USER/ADMIN 权限完全分离。
- 两端简单管理表单、用户编号检索、等级分配、三种优惠和活动/商品两业务范围隔离。
- 商城与活动服务端报价、下单变价确认、不可变价格快照、零元免支付。
- 活动独立支付退款/参与者快照/容量/超时关单，管理员名单和退款处理，通知兼容。
- 活动多人优惠无默认设置，管理员启用时必须显式选择。
- API、数据库及两端均只允许活动/商品两项规则，非法范围、缺项及重复/多余项均拒绝。

## 审查修复

独立审查及集成测试发现并修复：活动错订单支付查单回执、退款关闭/未知状态无后续入口、免支付误标付款、同请求号不同参与人未冲突、收费名册及通知遗漏、活动变价错误码不匹配、跨账号活动订单深链残留、管理员无法主动发起退款，小程序免支付取消入口，以及收费活动复制/模板生成误变免费草稿。

所有原有服务端回归断言保留。旧退款测试仅补充新增非空快照列的合成插入数据。小程序原“收费不可报名”断言根据新业务改为“收费进入费用确认”，并增加异常金额、收费订单、权限/变价/支付状态测试；未移除免费和状态边界校验，未跳过失败测试。
