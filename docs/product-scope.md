# Wildboy 户外活动小程序

## 本次交付目标

管理员发布、编辑户外活动，微信用户浏览并报名。首页严格沿用参考图的结构而非复制截图素材：沉浸式轮播、2×2 分类图卡、装备小店一览、双列活动流，滑动加载更多。

四个分类保留原始命名：本周活动、国内游行、假期活动、休闲活动。“国内游行”未擅自改为“国内旅行”，可在后续确认后统一改显示名，稳定分类代码 DOMESTIC 不受影响。

## 角色和生命周期

- 游客：浏览已发布活动及详情，不可读取报名人信息。
- 微信用户：服务端校验微信临时 code 后获得本系统会话；报名、查看自己的报名、在截止前取消。
- 管理员：后台创建草稿、编辑、发布和取消活动，查看对应报名名单。
- 草稿不公开。发布不等于报名永远可用，活动时间、报名截止时间、取消状态与容量在服务端校验。
- 活动取消保留历史；已报名状态应解释清楚，不伪造退款。
- 同一用户重复点击报名不能重复占名额；取消与重新报名、并发最后名额都需要事务保护。
- 活动修改采用版本检查；不得将容量改到已报名人数之下。

## 暂不包含

- 微信支付、收费报名、押金、退款、购物车、物流及装备下单。
- 真微信账号、真实活动参加者或线上运营数据的自动生成。
- 小程序正式发布、服务器购买、域名备案、商户号申请、支付密钥配置。

报名本期免费；装备小店仅展示，不承诺可购买。支付通过显式能力标志关闭；以后接入时需要订单、支付回调验签、幂等、关单、退款及对账完整设计，不仅加一个支付按钮。

## 技术取舍

- 微信客户端：原生小程序 TypeScript / WXML / WXSS，直接使用微信登录和原生交互，避免增加跨端框架适配成本。
- API：Spring Boot / Java 21，清晰的服务端校验与事务边界。
- 数据库：PostgreSQL，Flyway 版本化迁移。
- 管理后台：Vue 3 / TypeScript / Vite，独立运营入口。
- 图片：本项目原创 AI 配图，仅用于视觉示例；演示活动明确标注，不暗示照片对应真实出团。

## 实际上线前置项

需使用用户自行申请的小程序 AppID、服务端 AppSecret，HTTPS API 域名及微信后台合法域名、隐私保护指引。AppSecret 仅在服务端环境中提供，绝不写进小程序包。示例报名收集姓名/联系电话，正式运营必须根据用途进行最小化收集并完成隐私合规配置。

开发演示登录必须显式开启且不能用于生产。缺失微信配置不能悄悄回退成假登录。部署文档和最终验证报告将区分本地演示验证与微信真机/线上验证。
