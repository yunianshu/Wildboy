# 网页后台重构验收

[Pencil 设计图](../../design/设计图文件.pen)保存了 38 张新版画板，覆盖 18 个实际页面路由。打开画布后，在左上项目索引找到新版 Web 入口。新版画板位于右侧，以 `Web /` 开头，两块浏览器预览连接本地后台。旧版全端画板及探索页参考稿保留在同一文件中。[画板索引](../../design/web-admin-manifest.json)

Web 后台采用 200px 分组侧栏、52px 顶栏、36px 桌面按钮和 44px 窄屏控件。活动管理用紧凑表格呈现，窄屏改成纵向卡片。活动标题、分类、状态由服务端组合筛选，分页总数来自匹配结果。活动编辑分为基本信息、时间地点和详情，报名定价适用于桌面及窄屏。基础配置四个入口集中展示，每次编辑一个，整组保存。会员等级、用户业务身份和文章编辑支持分段切换并保留必要的表单状态。

## 本地复跑

本次报告使用 `127.0.0.1:15176` 的 Vite 和 `127.0.0.1:19082` 的隔离 API。浏览器脚本只接受它内置的本地端口组合，启用写入时会创建并清理业务样例。必须连接一次性数据库。

```powershell
$env:WILDBOY_E2E_TARGET = 'current'
$env:WILDBOY_E2E_ACCOUNT = '1'
$env:WILDBOY_E2E_WRITE = '1'
node tests/e2e/admin-redesign-browser.cjs
```
