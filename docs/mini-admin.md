# 小程序内管理

从“我的”中的“管理员身份验证”使用已配置的管理员账号/密码登录；只有服务端 `/me` 确认 ADMIN 后显示活动管理入口。普通微信用户不能通过直接页面地址使用管理接口。该登录切换当前会话，不将微信用户升级，也不保存密码。退出管理身份后可重新微信登录查看个人报名。

管理范围：全局状态分页列表、新建草稿、编辑、原创封面预设/HTTPS图片地址、发布日期/截止/名额等校验、保存草稿、确认发布、确认取消、分页名单与显式查看联系方式。活动报名免费，装备订单由独立商城与微信支付流程处理。活动变更与取消不会自动通知参加者，页面明确提示组织者另行联系。

管理页面每次显示和写入前重新验证角色；会话切换、后台返回、迟到请求不允许恢复旧私密名单。离开编辑页通过原生未保存提示确认；版本冲突不静默覆盖，需要显式重新读取。首次创建如果发生网络不确定结果，要求回列表核对，避免重试重复创建。名单默认隐藏完整号码，完整号码仅在再次验证权限后由管理员点击查看。

原生页面：`admin-login`、`admin-activities`、`admin-editor`、`admin-roster`。管理员账号继续使用服务端 ADMIN_USERNAME/ADMIN_PASSWORD_HASH，不在客户端添加默认管理员或硬编码密钥。生产环境不得启用开发登录。

本轮已用微信开发者工具连接真实本地 API 验证：管理员账号密码登录、活动列表、创建并发布、编辑版本、双人报名名单、权限复核显隐和活动取消。发布/取消使用页面内嵌确认层，避免原生弹窗触发生命周期导致操作失效；连续点击操作按钮不等于确认，账号切换仍阻止旧操作。证据位于 `test-results/wechat-admin/`，协议管理另由 `tests/e2e/wechat-legal-real.cjs` 独立验证。未据此声称真机或生产账号已验证。
