# 首页排版调整验收（2026-10-27）

## 需求与实现

- 安全拉取 `main`，基于 `647b6dc`（拉取时已为远端最新版本）修改，保留其他功能。
- 顶部一张静态沉浸图；四分类改为单行，但保留既有业务名称和筛选。
- 中间两列三行共六个活动位；有 1–5 条时按顺序循环补齐，6 条及以上取前六，0 条显示空态。仅创建前端展示对象，原活动 ID、名额和报名记录不变。
- 装备展示放到活动之后；底部图片自动轮播，可暂停/继续，默认间隔 5 秒。
- 更多活动通过“全部”入口，进入完整分页列表并清除前一次分类；首页不再触底追加活动，以免破坏固定六卡结构。
- 保留加载、失败重试、下拉刷新、过期响应保护、底部安全区、装备不可购买提示。
