# Web 后台地图选点（高德）

仅用于 Web 后台活动编辑 → 上车、导航与证件 → 添加导航点 → 地图选点。可搜索地点，也可以直接点地图。确认选点先回填名称、地址和 GCJ-02 坐标，不会自动保存活动。历史上车点、粘贴坐标和手动录入仍可用；小程序导航与历史数据不变。

## 启用

1. 在高德开放平台为 WildBoy 申请或复用专用 **Web 端（JS API）** Key，设置允许使用的后台域名；如需在本地真实联调，还要按实际访问地址配置开发域名。参见[高德申请指引](https://lbs.amap.com/api/javascript-api-v2/prerequisites)。
2. 将可公开到浏览器的 Web Key 注入构建进程的 `VITE_AMAP_JS_KEY`。未注入时地图入口不可用，其他录入方式不受影响。仅用于本地联调的 Key 可存入未跟踪的 `admin/.env.local`。
3. 按[高德安全密钥代理说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)在后台同源 HTTPS 站点配置 `/_AMapService`，由代理向固定的高德上游添加与 Web Key 配对的 `jscode`。不要把安全密钥放在任何 `VITE_*`、静态页面、Git 或聊天消息中，不要转发 Cookie 或业务 Authorization 到高德。代理应限定地图检索所需的路径与方法，校验项目 Key，限流并避免带密钥的查询写入日志。该配置需与实际网关一同验证，未配置的站点不要启用 Web Key。
4. 在管理员浏览器用真实地图试搜和选点、确认保存后从小程序打开同一个点，现场核对坐标。同时检查无 Key、代理错误、搜不到、关闭弹窗和地图网络失败时的回退。自动测试使用模拟高德接口，不消耗线上配额。

不要将搜索结果的地址和再次点选得到的不同坐标混用。地址反查未命中时返回坐标，管理员可以补填地址。
