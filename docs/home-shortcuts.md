# 首页入口基础配置

后台「基础配置」统一管理首页一行四个入口。固定槽位从左到右为 1–4，可修改名称（1–12 字）、内置图标/背景和行为，不改变活动分类、已有报名或文章正文。

## 默认与配置方式

- 本周活动 → 活动页本周筛选。
- 国内游行 → 活动页国内筛选。
- 二维码 → 弹窗。初始没有二维码图片，不生成、不填入示例二维码；点击明确显示暂未配置。运营者需在后台上传自己的真实二维码图片后保存。
- 野小子 → 当前官方介绍文章。后台文章管理更换官方介绍后自动跟随，无需再次修改入口配置。

行为支持：

1. **已有页面**：仅可选本周活动、国内游行、全部活动、商城、我的，不接受任意路由或外部链接。
2. **文章**：选择已发布文章，或「当前官方介绍文章」。文章下架后不能从入口阅读草稿；未配置官方介绍时明确显示不可用。点击前检查公开文章，文章页仍独立读取最新发布状态。
3. **弹窗**：标题、纯文本和图片。图片复用已有 JPG/PNG 上传（4 MB 限制），也可用安全的 HTTPS/`/assets/` 图片地址。保存不代表二维码有效性已核验；请用实际微信扫描检查。无图片和文字时显示空态，图片加载失败有提示；关闭按钮/遮罩可关闭，内容点击不会透传。

上传真实二维码前请核实目标与所有权；本功能不会自动创建二维码、添加好友、入群或触发支付。长按图片能力由微信原生组件提供，真机识别效果应另行测试。

## API 与并发

- `GET /api/v1/home/shortcuts`：公开，只返回入口展示配置；已下架指定文章的 `articleId` 清空，绝不返回草稿正文。
- `GET /api/v1/admin/home/shortcuts`：管理员读取当前版本与全部配置。
- `PUT /api/v1/admin/home/shortcuts`：管理员整体保存 `{version,items}`。必须恰好四个唯一槽位，服务端规范化排序、清空其他类型字段。版本不一致返回 `409 HOME_SHORTCUTS_CONFLICT`，编辑端保留输入并要求刷新，避免覆盖他人修改。
- 每项字段：`slot,name,icon,type,page,articleId,popupTitle,popupText,popupImageUrl`。`type` 为 `PAGE/ARTICLE/POPUP`；`icon` 为 `WEEKLY/DOMESTIC/QRCODE/INTRO`。默认/动态官方文章 ID 为 `OFFICIAL`。
- 保存通过数据库事务、版本检查及共享文章发布锁防止并发校验竞态，并写入 `HOME_SHORTCUTS_UPDATE` 审计事件。
- V14 Flyway 新增独立单例配置，不覆盖已有文章设置、活动类别或业务数据。

## 人工验收

1. 打开基础配置，确认四槽和默认名称；第三槽上传真实二维码，保存后首页点击弹出完整图片，关闭、再次打开及长按检查。
2. 改任一槽为商城，保存后应进入商城 Tab；改为已发布文章，应阅读指定文章；下架后不得读到草稿。
3. 第四槽选择当前官方介绍；更换官方文章后验证入口跟随。
4. 两个管理员同时打开配置，先保存者成功，后保存者收到版本冲突且输入保留。
5. 断网/图片失败/退出登录后旧请求不可恢复旧界面；首页入口加载失败可重试；四入口仍单行、活动最多四条且不重复。

仅代码与隔离测试，不自动更新生产配置或部署。微信真机/真实二维码扫码需运营者提供图片并在正式合法域名环境验收。
